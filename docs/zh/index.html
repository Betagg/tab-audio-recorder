快速答案

怎样录制 Chrome 网页里的声音？

打开正在播放声音的 Chrome 标签页，确认标签页和网页播放器没有静音，然后从 Dolphin 开始录制。录完后先检查波形和预览声音，再剪掉开头、结尾的多余部分并下载 MP3。

Dolphin 只处理你主动选择的当前标签页。它不会录制屏幕、麦克风、其他应用或所有标签页，也不会把录音上传到服务器。

适合的任务

保存课程、播客、访谈、直播回放或网页播放器中你有权保留的音频。

不适合的任务

录制整个电脑声音、多轨混音、麦克风采访或绕过受保护媒体。

六步流程

先做 10 秒测试，再完成正式录音

查看完整的标签页录音边界
  1. 打开目标标签页

    进入课程、播客、访谈或网页播放器，播放你有权保存的音频。

  2. 检查两处静音

    确认 Chrome 标签页没有静音，网页播放器的音量也不是 0。

  3. 从目标标签页开始

    保持目标页为当前标签页，点击 Dolphin 开始录制。

  4. 保持来源稳定

    录制期间尽量不要刷新、关闭、休眠或把声音切换到新的标签页。

  5. 停止并检查波形

    先录约 10 秒，停止后确认有波形，并预览是否能听到声音。

  6. 剪辑并保存 MP3

    拖动剪辑范围，预览保留部分，填写清楚的文件名后下载。

静音排查

没有波形或录音无声时，按这个顺序检查

先确认录制是否从真正播放声音的标签页启动，再检查 Chrome 标签页静音、网页播放器音量和播放状态。部分网站会把播放器打开到新标签页，原标签页此时不再产生声音。

如果一个网站仍然无声，换到普通公开音频页面做 10 秒测试。测试页正常，通常说明原网站、播放器、页面切换或媒体保护是原因；两个页面都失败时，再重启 Chrome 并检查扩展是否启用。

快捷键

用快捷键更快开始和停止

在 Chrome 扩展快捷键页面为 Dolphin 设置组合键。按一次开始录制当前标签页，再按一次停止。

快捷键适合声音突然开始的课程、直播或访谈，但仍建议先确认当前标签页和播放器确实有声音。

推荐设置 Chrome 扩展快捷键

在地址栏打开 chrome://extensions/shortcuts，找到 Dolphin，然后设置“开始/停止录制”的快捷键。

Dolphin 会在浏览器本地保存最多 50 条历史记录，包括网页标题、来源 URL、网站、时长、剪辑范围、文件名和保存时间。历史记录不包含 MP3 音频文件。

在插件中打开录音历史并选择清除历史，可以删除这些本地元数据。已经通过 Chrome 下载的 MP3 不会因此被删除。

常见问题

你可能会关心的问题

Dolphin 会录屏吗？

不会。Dolphin 只录制当前 Chrome 标签页的声音，不生成视频文件。

录音会上传到服务器吗？

不会。录音和 MP3 编码在本地完成，文件保存到你的设备。

可以录麦克风或整个电脑声音吗？

不可以。Dolphin 专注于当前浏览器标签页音频。

可以录所有网站吗？

不能保证。普通标签页音频通常可以尝试录制，但 DRM、受保护播放器、网站限制或 Chrome 安全边界可能让音频无法捕捉。

为什么录音没有声音？

常见原因包括从错误标签页开始、Chrome 标签页静音、网页播放器音量为 0、尚未开始播放，或网站把声音切换到了新的标签页。

正式录音前应该怎样测试？

从目标标签页录制约 10 秒，停止后检查是否出现波形，并预览声音。确认正常后再开始较长的录制。

可以在保存前剪辑吗？

可以。你可以调整波形的开始和结束位置，预览保留片段，再下载 MP3。Dolphin 不是多轨音频编辑器。

历史记录会保存录音文件吗？

不会。历史记录只保存网页标题、来源 URL、网站、时长、剪辑范围、文件名和保存时间等本地元数据，最多 50 条。

清除历史记录会删除 MP3 吗？

不会。清除历史只删除 Dolphin 本地保存的记录，已经通过 Chrome 下载的 MP3 仍保留在你的下载位置。

Dolphin 需要账号吗？

不需要。录制允许的标签页音频并保存 MP3 不需要创建 Dolphin 账号。
